# DDEditor

[English](README_en.md)

## 概要

DDEditor は、VRリズムゲーム「Dance Dash」向けの譜面編集ツールです。
楽曲情報や難易度情報などのメタデータを編集できるほか、2D/3D View 上でノーツ、ロングノーツ、障害物、ストリームノーツなどを配置・調整できます。
可変BPMの楽曲の譜面の制作も可能です。

> 本ツールは個人制作の非公式ツールです。  
> Dance Dash 本体および関連する権利は、それぞれの権利者に帰属します。

## 主な機能

- 音楽ファイルの再生
- 譜面データの読み込み
- 譜面データの編集
- 難易度ごとの譜面管理
- BPM・オフセットなどのタイミング設定
- 可変BPMの楽曲の譜面制作
- 2D / 3D 表示による譜面確認
- JSON形式のデータ読み込み・保存

## 動作要件

### 実行する場合

- Windows 10 / 11
- OpenGL 3.3 以降に対応した環境

### ソースコードからビルドする場合

- Windows 10 / 11
- Visual Studio 2022
- CMake 3.20 以降
- C++17 対応コンパイラ
- OpenGL 3.3 以降に対応した環境

## ダウンロード方法

ビルド済みのWindows版は、GitHub Releases からダウンロードできます。

1. このリポジトリの Releases ページを開きます。
2. 最新のリリースを選択します。
3. Assets から以下のzipファイルをダウンロードします。

```text
DDEditor-v1.0.0-win64.zip
```

4. zipファイルを任意の場所に展開します。
5. 展開したフォルダ内の `DDEditor.exe` を実行します。

## ソースコードからのビルド方法

このリポジトリには、ビルドに必要な外部ライブラリを `external/` 以下に同梱しています。

Visual Studio 2022 がインストールされた環境で、以下を実行します。

```bash
cmake -S . -B out/build -A x64
cmake --build out/build --config Release
```

Ninja を使用する場合は、Visual Studio 2022 の Developer PowerShell または Developer Command Prompt で以下を実行してください。

```bash
cmake -S . -B out/build/x64-Release -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build out/build/x64-Release
```

Visual Studio の CMake連携を使用している場合は、Visual Studio 2022 でこのフォルダを開いてビルドすることもできます。
